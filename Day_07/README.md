# Project Execution Topics

## **constitution**
These are the **immutable standards** and foundational rules that apply to all work within a project.
They establish the non-negotiable guiding principles for the entire development process.

## **specify**
This involves writing **clear, detailed specifications** that define exactly what the final product or feature must do.
Good specifications ensure all project members understand the desired outcome.

## **clarify**
The process of actively **identifying and resolving any missing requirements** before implementation begins.
This step prevents costly rework by ensuring all needs are known and precise.

## **plan**
Generating a comprehensive **step-by-step implementation plan** to guide the execution of the project.
The plan defines the order of operations, resources, and dependencies for success.

## **tasks**
This means breaking down larger pieces of work into **small and independent units** that are easily manageable.
small tasks are essential for efficient tracking and delegation.

## **implement**
The direct **execution of the planned tasks**, often using artificial intelligence (AI) to automate parts of the work.
This is where the actual code or output is produced based on the specifications.
